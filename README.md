# RAG Document Intelligence

A Retrieval-Augmented Generation (RAG) system that retrieves relevant information from PDF documents and generates context-grounded answers.

## Features

- PDF document loading and text extraction
- Recursive text chunking
- Sentence Transformer embeddings
- ChromaDB vector database
- Semantic document retrieval
- Context-based question answering

## Workflow

PDF → Text Extraction → Chunking → Embeddings → ChromaDB → Retrieval → LLM → Answer

## Technologies

- Python
- LangChain
- Sentence Transformers
- ChromaDB
- Hugging Face Transformers
- PyPDF
- Google Colab
